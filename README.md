Image files used by the PFC framework: the pictures of PFC's own objects (the message box's icons, the drag-and-drop Sort dialog box's drag icons, and the lines, boxes and folders of a printed TreeView), and `pfc.pbr`, PFC's resource file.

## Which versions of PFC use these files

| Version | Its images |
|---|---|
| [2022](https://github.com/OpenSourcePFCLibraries/2022) | **This repository.** Add its folder to the system path or to PowerBuilder's application path, or compile the images into the executable with `pfc.pbr`. |
| [2019](https://github.com/OpenSourcePFCLibraries/2019) | The same images, in that repository's `images` folder. It doesn't need this repository. |
| [2025-Solution](https://github.com/OpenSourcePFCLibraries/2025-Solution) and [2025-Workspace](https://github.com/OpenSourcePFCLibraries/2025-Workspace) | Current images (SVG, PNG and ICO, named `pfc_*`) in `pfc libs/images`, and a new `pfc libs/pfc.pbr`. They don't use this repository. |
